# Gotchas

- Default `Python-urllib` and bare-agent requests can get Cloudflare 403 (error 1010) before the Worker runs. Send a descriptive User-Agent.
- `@cloudflare/vitest-plugin` with `cloudflareTest()` and `readD1Migrations` in `worker/vitest.config.ts`; tests import `env` from `cloudflare:workers` and `applyD1Migrations` from `cloudflare:test`.
- Handlers take `deps` (`fetch`, `now`, `sleep`) so tests stub GitHub, OSV and time without network; see `worker/test/helpers.ts`.
- The session cookie works because the site and `/api` share one origin.
- Session and OAuth state cookies are `__Host-ch_session` and `__Host-ch_state` on https; plain names only on http://localhost.
- Cookie sessions refuse writes whose `Origin` differs from `PUBLIC_ORIGIN` (localhost allowed when `PUBLIC_ORIGIN` is localhost). API keys skip that check and cannot create or revoke keys. `npm run dev -w worker` passes `--local-upstream localhost:8787`; plain `wrangler dev` makes every local save look cross-site.
- `PUT /api/dev/secrets` and key management are browser-only; tests that need a token must sign in with a cookie.
- Never rename the Worker `clodhub`: a new name deploys a new Worker without the secrets, and `MASTER_KEY` cannot be read back.
- Sign-in answers 503 "GitHub sign-in is not available yet" when the OAuth secrets are missing; reading and API-key publishing do not need them.
- Client-facing error text must be thrown as `HttpError`; any other error becomes a generic 500 with a reference (`errorResponse` in `worker/src/index.ts`). Plain `Error` messages can name private repositories.
- Token hashes carry the `h2:` prefix and are peppered from `MASTER_KEY`; verification also tries `MASTER_KEY_PREVIOUS` and plain SHA-256. Compare only through `hashMatches`.
- Cache API keys use `${PUBLIC_ORIGIN}/__cache/...`.
- Grid children need `min-width: 0` or a long URL widens the page on phones; `style.css` sets it for `.stack`, `.grid-2`, `.grid-3` and the card layouts.
- Headless desktop Chrome will not open narrower than about 500 px; use `npx playwright screenshot --channel chrome --viewport-size=390,844`.
- `site/public/contract.md`, `site/public/docs/package-foundations.md` and `site/public/free-tiers.md` are generated (gitignored); edit `CONTRACT.md`, `docs/package-foundations.md` and `site/src/freeTiers.ts`.
- `catalogue_fts` rows are not removed with their entries: remove entries only through `CatalogueDb`, and clear the full-text tables before the entry tables in test cleanup (`clearDb`). Deleting a developer orphans their entries.
- Search text goes through `ftsQuery`; never pass user text to `MATCH`.
- Catalogue names use the short name (`slug`) in routes and are unique across scopes.
- A recipe's `page.diagram` is SVG text served as an image from the Worker, never inserted into a page as markup.
- SQLite CHECKs pass on NULL: `CHECK (a IS NOT NULL OR b = 'x')` accepts a NULL `b`; use `COALESCE(b, '')`.
- Unauthenticated `api.github.com` asset requests return JSON metadata unless `Accept: application/octet-stream` is sent; `fetchUpstream` sets it.
- Class references must be `clodhub/<name>` (`isClassReference` in `shared/src/foundations.ts`). Interface documents declare entry modules under `x-clodhub-modules` (`INTERFACE_MODULES_KEYWORD`, read through `documentModules` in `shared/src/catalogue.ts`); no other prefix is accepted.
- Changing `docs/package-foundations.md`'s example descriptor changes its digest; the parity test in `shared/test/foundation-parity.test.mjs` checks it.
